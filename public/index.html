ກົດເຫຼັກ 5 ຂໍ້

  1. SL ຕັ້ງໃນ MT5 ຕັ້ງແຕ່ກົດເຂົ້າ. ບໍ່ມີ SL = ບໍ່ເຂົ້າ.
  2. ລາຄາແຕະ SL = ອອກ. ບໍ່ຍ້າຍ SL ໜີ, ບໍ່ "ລໍໃຫ້ມັນກັບມາ".
  3. ຍ້າຍ SL ໄດ້ທາງດຽວ: ເຂົ້າຫາກຳໄລ (ເຊັ່ນ breakeven ເມື່ອໄດ້ 1R).
  4. ເສຍແລ້ວ ພັກ 30 ນາທີ. ເສຍຄົບກຳນົດຂອງມື້ ປິດ MT5.
  5. ໄມ້ທີ່ cut loss ຕາມແຜນ ແມ່ນໄມ້ທີ່ເຮັດຖືກ, ເຖິງຈະຂາດທຶນ.
ກົດເກນ (ຄືກັນກັບ EA Gold Guardian): trend ຕາມ EMA 50/200, ເຂົ້າເມື່ອລາຄາກັບຄືນເໜືອ / ລຸ່ມ EMA 20, SL = ATR×ຄູນ, TP = SL×R:R. ເຂົ້າທີ່ແທ່ງຖັດໄປ, ລວມ spread. ຖ້າແທ່ງດຽວແຕະທັງ SL ແລະ TP ນັບວ່າໂດນ SL.

ຕິດຕັ້ງແອັບນີ້ໃສ່ໂທລະສັບ Android

  1. ເປີດລິ້ງແອັບນີ້ໃນ Chrome ແລ້ວເຂົ້າສູ່ລະບົບ Claude.
  2. ກົດ ⋮ (ມຸມຂວາເທິງ) → "ເພີ່ມໃສ່ໜ້າຈໍຫຼັກ" (Add to Home screen).
  3. ຕັ້ງຊື່ "ທີມເທຣດທອງ" ແລ້ວກົດເພີ່ມ. ໄອຄອນຈະຢູ່ໜ້າຈໍໂທລະສັບ, ກົດເທື່ອດຽວກໍເຂົ້າໄດ້.
  4. ຫຼື ເປີດໃນແອັບ Claude: ແຖບ Artifacts ຈະມີແອັບນີ້ຢູ່ສະເໝີ.

EA "Gold Guardian" ສຳລັບ MT5 ແກ້ບັນຫາບໍ່ຍອມ cut loss

EA ນີ້ແລ່ນໃນ MT5 ຂອງເຈົ້າເອງ, ລະຫັດບັນຊີບໍ່ອອກຈາກເຄື່ອງ. ມັນ:

  • ໃສ່ SL ໃຫ້ອັດຕະໂນມັດ ຖ້າເຈົ້າເປີດໄມ້ໂດຍບໍ່ມີ SL
  • ຍ້າຍ SL ກັບຄືນທັນທີ ຖ້າເຈົ້າຍ້າຍມັນໜີ ຫຼືລຶບອອກ
  • ປິດໄມ້ທອງທັງໝົດ ແລະລັອກທັງມື້ ເມື່ອເສຍເຖິງ 3%
  • ປິດໄມ້ທີ່ເປີດພາຍໃນ 30 ນາທີຫຼັງເສຍ (ກັນເທຣດແກ້ແຄ້ນ)
  • ປິດໄມ້ທີ່ lot ໃຫຍ່ເກີນ: ຖ້າໂດນ SL ແລ້ວເສຍເກີນ 2 ເທົ່າຂອງ % ທີ່ຕັ້ງໄວ້
  • ຍ້າຍ SL ມາບ່ອນເຂົ້າ (breakeven) ໃຫ້ເອງ ເມື່ອໄດ້ກຳໄລ 1R
  • ສົ່ງສັນຍານ BUY / SELL ພ້ອມ Entry, SL, TP, Lot ເຂົ້າແອັບ MT5 ໃນໂທລະສັບ (ບໍ່ກົດເທຣດເອງ)
  1. ໃນ MT5 ຄອມ: ກົດ F4 ເປີດ MetaEditor → New → Expert Advisor → ຕັ້ງຊື່ GoldGuardian.
  2. ລຶບໂຄດເດີມອອກ, ວາງໂຄດຂ້າງລຸ່ມ, ກົດ Compile (F7). ຕ້ອງບໍ່ມີ error.
  3. ລາກ GoldGuardian ໃສ່ກຣາຟ XAUUSD, ເປີດ "Algo Trading". ທົດລອງໃນບັນຊີ Demo ຂອງ IUX ກ່ອນ.
  4. ເພື່ອຮັບແຈ້ງເຕືອນໃນໂທລະສັບ: ເອົາ MetaQuotes ID ຈາກແອັບ MT5 ມືຖື (Settings → Messages) ໃສ່ MT5 ຄອມ: Tools → Options → Notifications.
  5. MT5 ຕ້ອງເປີດຕະຫຼອດ. ຖ້າປິດຄອມ ໃຫ້ໃຊ້ VPS.
